# Official character portraits (canon trainers)

80x80 trainer sprites from the Pokémon Showdown mirror, for the ~22 CANON
characters the game features (challenge gym leaders, Ash/Gary/Red/Lance,
the professors). Generated people keep their procedural anime portraits —
TrainerArt.has_art() decides, Portrait.avatar() routes.

    https://play.pokemonshowdown.com/sprites/trainers/<name>.png

Slugs match TrainerArt.slug(display_name): "Lt. Surge" -> lt_surge.png.
Note ash_ketchum.png <- ash.png and gary_oak.png <- blue.png upstream.

Nintendo/Game Freak/Creatures IP — personal fan project only, never
distribute commercially.
